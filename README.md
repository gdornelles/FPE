# Nova Regra do FPE

Proposta de repartição do Fundo de Participação dos Estados a partir de 2027.

- `index.html`: página inicial, com as quatro opções
- `painel.html`: painel interativo (regra atual → proposta, mapa, fundo, Congresso)
- `cenas.html`: a proposta em 11 cenas animadas
- `arquivos/FPE_proposta_fundo_compensacao.xlsx`: planilha com todos os cálculos
- `arquivos/FPE_nova_formula_explicada.pdf`: explicação didática
- `arquivos/A_Proposta_do_FPE_em_Cenas.pdf`: as cenas em PDF

Site estático, sem instalação. Para publicar: Settings → Pages → Build and deployment → Source: *Deploy from a branch* → Branch: `main`, pasta `/ (root)` → Save.

Dados: IBGE 2025 (população e renda domiciliar per capita); LC 62/1989 com redação da LC 143/2013; estimativa da SEFAZ/PE para a divisão do FPE de 2027. Mapa: svg-maps/brazil, de Victor Cazanave, licença CC BY 4.0.
